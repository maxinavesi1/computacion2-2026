# Este TP no usa dependencias de terceros a propósito.
#
# La TUI está hecha con `curses`, que es parte de la stdlib de Python en
# Linux (no hace falta pip install). Se evaluó usar `rich`, pero curses

# por vista, sin sumar una dependencia externa innecesaria.
#
# Si en algún momento se agrega una dependencia real, va acá con versión
# fijada, por ejemplo:
#   rich==13.7.1
